# PRD: AI-Native Tech Analyst & LinkedIn Publisher

## Project Overview
An autonomous agentic pipeline that scours high-tech, AI, and startup news to identify high-signal content tailored for a CTO/PhD-level technical audience. The system facilitates a Human-in-the-Loop (HITL) workflow where the user selects the best topic before the agent drafts and optimizes a LinkedIn post.

## Target Audience Persona
- **Role:** CTO, Senior Technologist, PhD in AI/Computer Science.
- **Interests:** MCP (Model Context Protocol), Agentic Workflows, Multi-agent orchestration, Enterprise SaaS (AI-native), and Longevity/HealthTech research.
- **Tone:** Professional, insightful, technical but accessible, forward-looking.

## Core Features
1.  **Multi-Source Scraper:** Aggregates news from ArXiv, Hacker News, and specialized tech feeds.
2.  **Relevance Analyst:** Filters noise using a "PhD/CTO Filter" to prioritize architectural shifts over hype.
3.  **HITL Interrupt:** Pauses execution for user selection or confirmation.
4.  **LinkedIn Content Architect:** Drafts structured posts with hooks, technical insights, and calls to action.
5.  **Self-Critique Loop:** Scores drafts against professional standards before final approval.

## Success Metrics
- Signal-to-noise ratio: >80% of suggested articles should be relevant to the user's background.
- High engagement potential on LinkedIn through technical depth.
